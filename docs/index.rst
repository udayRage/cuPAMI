cuPAMI documentation
====================

cuPAMI provides CUDA implementations of pattern mining algorithms, developed at
The University of Aizu under Professor Rage Uday Kiran.

Start with installation and a small mining example, then choose an algorithm guide.
The API reference documents constructor arguments and public methods directly
from the source, following PAMI's Sphinx documentation structure.
